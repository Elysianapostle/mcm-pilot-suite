# 04 论文写作 + 插图规范

> 论文手主责，代码手协助出图，建模手配合。

---

## 一、通用结构（三题一致，无一例外）

```
摘要（结构化，分问题给数值）
→ 问题重述 → 问题分析 → 模型假设 → 符号说明
→ 模型建立与求解（按问题一/二/三分节，每节：建模→求解→结果）
→ 模型检验/灵敏度分析 → 模型评价与推广 → 参考文献 → 附录（代码）
```

---

## 二、摘要写法（最后写，最关键）

- 逐题"**针对问题 X，采用…方法/模型，得到…（带具体数字），结论…**"。
- **数字越具体越好**：如"激活率 7.46%""R²=0.9999""补贴 2~10 元""完成率提高 24.5%"。
- 不要空泛（"我们认为…""本文将…"），不要放公式和表格。

---

## 三、各题型的写作侧重

| 题型 | 写作侧重 |
|---|---|
| A 题 | **问题分析段是评阅重点**，每子问"难点是什么 → 为什么用这个思路 → 用什么方法解"；结果必须"图文表三件套"（数值正文 + 曲线图 + 多组结果表） |
| B 题 | **问题分析"给思路不堆公式"**（分析末尾放思路流程图）；假设带论证（3.1 假设 + 3.2 可行性）；有目录 + 附录源码加分 |
| C 题 | 摘要分条给数值；**大量表格承载结果**（回归表、频数表、聚类规则表）；附录放**可复现的完整代码** |

---

## 四、常见写作错误（防错清单）

- 假设没在正文建模处引用 → 形同虚设。
- 结论只给数值不解释含义 → "最优值 1234.56"却不说明对应什么方案。
- 图表出现但正文没引导和解释 → 评委不知道图要说明什么。
- 公式符号首次出现处没定义。
- 连续三张图中间没文字 → 论文变图集。
- 参考文献捏造或无法核实。

## 五、插图规范

### 5.1 通用时序规律

> **核心铁律：每道题的每个子问题都必须做可视化，边建模边写可视化代码，不要等最后统一出图。** 可视化是分析过程的一部分，不是结果后处理。优秀论文的共性就是每道题至少 4-6 张图，且每张图后紧跟一句从图读出的结论。

| 时机 | 插什么图 | 三题共性 |
|---|---|---|
| **问题分析/开篇** | 技术路线图、思路流程图 | B 题用得多，A 题几乎不用 |
| **数据探索阶段** | 散点图、折线、频数柱状/饼图、地图热力 | C 题最密集 |
| **模型建立阶段** | 机理/受力/结构/坐标系示意图 | **A 题最密集（评审重点）** |
| **模型求解阶段** | 算法流程图、仿真演化图 | 三题都有 |
| **结果呈现阶段** | 拟合对比图、残差图、结果曲线 | 三题都有 |
| **结尾检验** | 灵敏度分析图/表 | 三题都有 |

### 5.2 各题型的插图特点

**A 题**：
- **图最密集的地方是"模型建立/受力分析"，而不是"结果"** —— A 题评审看"你怎么把物理对象拆开建模"，受力图/机理图数量远多于结果图。
- **反直觉发现**：获奖论文几乎**不用总技术路线图**，只在求解局部放**算法流程图**。很多辅导书强调的技术路线图，在真实一等奖 A 题论文里并不流行。

**B 题**：
- "**边建模边配图**"：分析放路线图 → 数据探索放地图/散点/热力 → 模型建立放结构/类比图（如 2016B 用"电路图类比交通流"，很有辨识度）→ 求解放仿真演化（成对"未开放 vs 开放"对比）→ 结尾灵敏度。

**C 题**：
- "**探索在前、结果在后、方法插结构图**"：建模前放散点图（2017C 连插 16 幅 RGB 散点图）、建模后放拟合对比 + 残差、方法说明处放结构图（E-R 图、AHP 层次结构）。

### 5.3 caption 铁律

1. **图注必须自解释**：`图 X 对象 + 内容`，如"图 10 风速 12m/s 时锚链的形状"。
2. **图后紧跟一句从图读出的结论**，不能只贴图不说话。
3. **图例说明数据含义**：如"+ 代表拟合值、o 代表实测值"。
4. **结果对比优先用表格**而非图（路线表、频数表、回归系数表）。

### 5.4 总流程图模板（与 norms/数学建模规范.md I5 对齐）

- 模板四选一：**roadmap-5band**（竖版五带"破题→准备→方法→求解→评价"，默认）/ **stageflow-3col**（分阶段执行流程）/ **taskflow-land**（横向任务流水线，宽 1360，适合 Q1→Q4 任务递进或横排版面）/ **framework-3col**（研究框架全景）；渲染输出 drawio+PNG+PDF，正文引用 PDF 矢量（相对路径）。
- **A 题通常豁免总技术路线图**（见 5.2），只在求解局部放算法流程图；B/C 题问题分析处必放总流程图。
- 画面文案遵循模板字数预算，渲染报超框（OVERFLOW）时缩短文案或用 `\n` 断行；图中数值与正文一致、可溯源；图文件名 ASCII。
