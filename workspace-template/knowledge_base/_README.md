## 二、知识边界说明（重要）

**本知识库只教"怎么做"，不含完整成品参考。**

- ✅ 知识库涵盖：方法论、套路、决策树、负面案例、历年方法速查。
- ❌ 知识库**不含**：历年真题的完整获奖论文全文、完整 LaTeX 成品样例、具体某题的完整实现代码。
- ⚠️ 遇到完全陌生领域题（如某年新出现的医学/光学/农业场景）：知识库只能提供"怎么拆解 + 查什么外料 + 用什么套路"，**无法提供该领域的成品对照**。此时：
  1. 建模手从 `06_四维趋势` + `01_题外资料` 出发确定方法骨架；
  2. 论文手从 `04` 的八段式结构搭全文框架，用表格/图承载结果补足"成品感"；
  3. 不要因为知识库没有该领域样例就慌——评审看的是**建模逻辑自洽 + 数字具体 + 检验完备**，不是领域知识深度。

## 三、Agent 检索入口

各子 Agent 的检索优先级见 `_AGENT_PROTOCOL.md` 第二节。一句话摘要：

- **知网收集者**：自动搜索 CNKI，不依赖知识库
- **物理手**：11 → 10 → 03 → 00（方法论 → FP策略 → 解法 → 总览）
- **建模手**：00 → 01 → 02 → 03 → 06（决策树 → 外料 → 假设 → 解法 → 趋势）
- **代码手**：03 → 06 → 05 → 08 → 00（解法 → 趋势 → 速查 → 调试 → 总览）
- **论文手**：04 → 06 → 09 → 07 → 05（写作 → 趋势 → 扣分清单 → 分工 → 速查）

**工具使用规则**：默认用 RAG 片段检索；仅以下白名单允许 read_md 读全文——`00_选型决策树`、`05_完整赛题表格`、`_README.md`、`_AGENT_PROTOCOL.md`。详见协议文件。
