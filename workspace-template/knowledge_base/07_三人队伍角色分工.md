## 二、建模手

**通用（老论文打底）**
- 拿到题先走**选型决策树**（00_国赛总览）：输出是数→优化、序列→预测、排名→评价、方程→机理、规律→统计。
- **假设三档**（02_合理假设方法论）：标配写全 + 加分项「化简 + 给依据」+ 避开「把结论假设掉」。
- **题外资料**（01_题外资料查询指南）：A 查硕博论文/国标、B 查国标/经验值、C 查标准公式/现成模型。

**近五年新增（新论文拔高）**
- **B 题先判题型，勿默认 0-1 规划**：统计回归（2021B）→ 几何定位（2022B）→ 几何机理（2023B）→ 概率决策（2024B）→ 物理反演（2025B），纯 0-1 已退场。
- **数学证明成硬门槛**：2022B 引理 + 集合唯一性、2023B「坡面重叠率定义」的批判性修正。
- **概率统计**：2024B 贝叶斯 Beta 先验 / 功效函数、2025C LMM(REML) / Z 值 / FDR。
- **题外资料升级**：从国标/经验值转向物理定律（光学 Fresnel/Snell）、医学文献（NIPT）、测绘规范（GB 海道测量）。

## 三、代码手

**通用（老论文打底）**
- A 题：有限差分 / 搜索算法（二分/黄金分割）/ fsolve / 最小二乘反演。
- B 题：0-1/整数规划、模拟退火、深度搜索、元胞自动机仿真。
- C 题：SQL/Excel/Python 清洗 → sklearn 由简到繁。

**近五年新增（新论文拔高）**
- **Python 生态取代 Matlab**：numpy/pandas/scipy.optimize/cvxopt/sklearn/lightgbm。
- **多求解器并存**：Gurobi（2024C 精确）vs 遗传算法（MATLAB）vs 差分进化 DEGA（Python）；动态规划（2024B/2025C）。
- **信号处理**：2025B FFT 选频 + 去基线 + 滤波（scipy.signal）。
- **深度学习**：2023C GRU、2025C MLP/LSTM/DeepHit + LightGBM 堆叠。
- **交互可视化**：plotly / 交互网页（2025C C023）当落地亮点。

## 四、论文手

**通用（老论文打底）**
- **八段式结构**：摘要→重述→分析→假设→符号→建模求解→检验→评价→附录。
- **摘要最后写**：逐题「方法 + 模型 + 具体数字」。
- **插图时序**：建模前 EDA → 建模配机理图 → 求解配流程图 → 结果配对比图 → 结尾配灵敏度。

**近五年新增（新论文拔高）**
- **摘要分问量化**：每问给 6 位小数精确结果 + 算法名 + 对比结论。
- **验证/诊断图**：Q-Q 图、残差图、收敛曲线、混淆矩阵——「图证收敛」是标配。
- **AI 使用声明（2025 新规）**：要么明写「未使用 AI」（2025C C023），要么明写工具并配足诊断（2025C C132 引 DeepSeek/Kimi）——2025 起不声明会失分。
