## 二、机理与公式要点（供建模使用）

> 单位约定：$r$ 径向坐标 [m]；$t$ 时间 [s]；$T$ 热力学温度 [K]；$C$ 或 $M$ 干基含水率 [kg 水/kg 干物质]；$D$（及 $D_{\text{eff}}$）水分扩散系数 [m²/s]；$k$ 导热系数 [W/(m·K)]；$\rho$ 表观密度 [kg/m³]；$c_p$ 比热容 [J/(kg·K)]；$L_v$ 汽化潜热 [J/kg]；$h$ 对流换热系数 [W/(m²·K)]；$h_m$ 对流传质系数 [m/s]；$R$ 通用气体常数 = 8.314 J/(mol·K)。

1. **圆柱坐标一维轴对称非稳态扩散方程**（出处 [1][2]）
$$\frac{\partial C}{\partial t}=\frac{1}{r}\frac{\partial}{\partial r}\left(rD\frac{\partial C}{\partial r}\right)$$
   含义：描述含水率沿半径方向的瞬态重新分布；$r=0$ 处由对称性得 $\left.\partial C/\partial r\right|_{r=0}=0$。当 $D$ 为常数时退化为 $\partial C/\partial t = D\left(\partial^2C/\partial r^2 + \frac{1}{r}\partial C/\partial r\right)$，其无限长圆柱解为 Bessel 函数级数 [1][2]。

2. **质量对流的第三类边界条件**（出处 [1][2][17]）
$$\left.-D\frac{\partial C}{\partial r}\right|_{r=R(t)}=h_m\left(C_s-C_\infty\right)$$
   含义：表面水分扩散通量等于对流带走的蒸汽通量；$C_s$ 为表面平衡含水率（由热风温度与相对湿度经等温吸附线给出）、$C_\infty$ 为热风对应的平衡含水率。**若只取第一类边界（表面含水率瞬间等于 $C_\infty$），干燥时间会被严重低估。**

3. **圆柱内能量方程（含潜热汇）**（出处 [3][4][13][14]）
$$\rho c_p\frac{\partial T}{\partial t}=\frac{1}{r}\frac{\partial}{\partial r}\left(kr\frac{\partial T}{\partial r}\right)+\rho_d L_v\frac{\partial C}{\partial t}$$
   注：右端第二项为汽化吸热源项，其符号取决于 $\partial C/\partial t$ 的定义方向；若写成"单位体积汽化速率 $\dot m_v$"，则为 $-\dot m_v L_v$。物理含义：水分汽化从物料内部取热，形成表面/内部降温，是热风干燥中"物料温度低于热风温度"的原因 [8][13]。结合水的有效汽化潜热通常低于纯水 $L_v$，可写成 $L_v$ 乘以含水率相关修正系数 [14]。

4. **表面对流换热边界（含蒸发散热）**（出处 [4][13][17]）
$$\left.-k\frac{\partial T}{\partial r}\right|_{r=R(t)}=h\left(T_\infty-T_s\right)-L_v\,j_w,\qquad j_w=-D\rho_d\left.\frac{\partial C}{\partial r}\right|_{r=R(t)}$$
   含义：表面能量收支 = 热风对流给热 − 蒸发带走潜热；$j_w$ 为表面水分蒸发通量 [kg/(m²·s)]。当接近湿球条件时等式右端趋于 0，表面温度停止上升，这是"恒速干燥段"的物理判据。

5. **Luikov 型热湿耦合方程组**（出处 [3]，耦合项形式参见 [5]）
$$\frac{\partial C}{\partial t}=\nabla\cdot\left(D_m\nabla C+D_T\nabla T\right),\qquad \frac{\partial T}{\partial t}=\nabla\cdot\left(a_q\nabla T\right)+\frac{\varepsilon L_v}{c_p}\frac{\partial C}{\partial t}$$
   含义：$D_m$ 为等温湿分扩散系数 [m²/s]，$D_T$ 为热梯度扩散系数 [m²/(s·K)]，$a_q=k/(\rho c_p)$ 为热扩散率 [m²/s]，$\varepsilon$ 为相变准则数（无量纲，液相向汽相转变的比例），$\varepsilon=0$ 表示无相变、$\varepsilon=1$ 表示全部在内部汽化。**这是"纯 Fick 扩散"之上的升级版控制方程。**

6. **Arrhenius 型有效扩散系数**（出处 [6][8]）
$$D_{\text{eff}}=D_0\exp\!\left(-\frac{E_a}{RT}\right)\quad\Longleftrightarrow\quad \ln D_{\text{eff}}=\ln D_0-\frac{E_a}{R}\cdot\frac{1}{T}$$
   含义：$D_0$ 为指前因子 [m²/s]，$E_a$ 为干燥活化能 [J/mol]。**$T$ 必须是开尔文温度**；用法是取若干风温下的 $D_{\text{eff}}$，对 $1/T$ 作线性回归，斜率 $-E_a/R$ 给出 $E_a$（[8] 即按此流程得 $E_a=33.145\ \mathrm{kJ\cdot mol^{-1}}$）。

7. **干燥动力学指标与经验模型**（出处 [6][7][8]，综述见 [S15]）
$$\mathrm{MR}=\frac{M-M_e}{M_0-M_e},\qquad \text{Page: } \mathrm{MR}=\exp\!\left(-kt^n\right),\qquad \text{Midilli: } \mathrm{MR}=a\exp\!\left(-kt^n\right)+bt$$
   含义：$\mathrm{MR}$ 为水分比（无量纲），$M_0$、$M_e$ 分别为初始与平衡干基含水率，$k$ 为干燥常数 [s⁻ⁿ]，$n$ 无量纲指数，$a,b$（Midilli 的 $b$ 量纲为 s⁻¹）为修正系数。干燥速率 $-\mathrm{d}M/\mathrm{d}t$ 与 $-\mathrm{d}\mathrm{MR}/\mathrm{d}t$ 成正比。

8. **干基含水率的定义与终点判据**（定义出处 [8]）
$$M=\frac{W_w-W_d}{W_d}\ \ [\mathrm{kg\ 水/kg\ 干物质}]$$
   含义：$W_w$ 为湿重、$W_d$ 为绝干重（[8] 中在 105 ℃ 下烘至恒重测定）。本题终点取"中心处 $M\le 0.15$"。**注意干基 0.15 等价于湿基 $0.15/1.15\approx 13.0\%$，切勿与湿基 15% 混用。**

9. **收缩关系（尺寸随含水率变化）**（出处 [10]；实测数据见补充条目 [S2]）
$$\frac{V}{V_0}=a+b\,\frac{M}{M_0}\quad(\text{理想收缩取 } a+b=1),\qquad \frac{R(t)}{R_0}=f\!\left(\frac{M}{M_0}\right)$$
   含义：体积（或半径）与含水率之间的经验关联；"理想收缩"指体积减少量等于失水体积。实测表明该线性关系只是近似——木瓜片在 50 ℃ 下体积收缩与失水偏离线性约 10%、60 ℃ 下偏离低于 5%，且高度收缩（76%–87%）远大于面积收缩（15%–26%），即收缩是**各向异性**的 [S2]。

10. **移动边界与 ALE 坐标变换**（出处 [11][12]）
    $$\xi=\frac{r}{R(t)}\in[0,1],\qquad \left.\frac{\partial C}{\partial t}\right|_{r}=\left.\frac{\partial C}{\partial t}\right|_{\xi}-\frac{\xi\dot R}{R}\frac{\partial C}{\partial \xi}$$
    含义：把随时间收缩的物理域 $[0,R(t)]$ 映射到固定计算域 $[0,1]$，附加对流速度 $\xi\dot R/R$ 修正；$\dot R=\mathrm{d}R/\mathrm{d}t$ 由收缩关系 $R(M)$ 链式求导得到。ALE 有限元法 [12] 是更一般的实现路线。**若不引入该修正而直接在固定网格上算变边界，会引入与网格移动速度成正比的虚假通量。**

11. **变物性的常见经验形式**（出处 [15][16]）
    $$\rho(C)=\rho_d(1+C),\qquad c_p(C)=\frac{c_{p,d}+C\,c_{p,w}}{1+C},\qquad k(C)=k_d+\beta_k C$$
    含义：第一式为"表观密度 = 干物质密度 + 含水体积贡献"的加和模型（$\rho_d$ 干基密度 [kg/m³干物质]，$C$ 干基含水率 [kg/kg]）；第二式是质量加权比热（$c_{p,d}$、$c_{p,w}$ 分别为干物质与水的比热）；第三式为导热系数随含水率的线性近似（$\beta_k$ 为经验系数 [W/(m·K·(kg/kg))]）。[15] 的对比计算表明取常数物性会明显偏离变物性结果；[16] 给出了密度、导热系数、热扩散系数、比热容随含水率的实测变化。**具体系数须按所选药材标定或做灵敏度扫描，不得直接套用他种物料。**

## 四、建模陷阱与竞赛评分提示

1. **温度必须用开尔文。** Arrhenius 式中的 $T$ 是热力学温度 [K]；若误用摄氏度，$E_a$ 的回归值会离谱（甚至出现负活化能）。同理，拟合 $\ln D_{\text{eff}}$ 对 $1/T$ 时横轴单位是 K⁻¹。[8] 正是按此流程得到 33.145 kJ/mol。

2. **"中心含水率 ≤ 0.15" 与"平均含水率 ≤ 0.15"差别很大。** 一维轴对称条件下中心最湿、最晚达标，用平均含水率代替中心含水率会显著低估干燥时间。论文中必须明确写出判据取在整个域的最低点（$r=0$），并给出中心节点的时间序列曲线。

3. **干基 / 湿基含水率必须全篇统一。** 干基定义 $M=(W_w-W_d)/W_d$ [8]；干基 0.15 约等于湿基 13.0%。混用会把终点判断整体搬移，属于典型扣分点。

4. **显式差分格式的稳定性与收敛性。** 扩散方程的显式格式时间步受 $D\Delta t/\Delta r^2$（Fourier 数）限制，圆柱坐标下 $r=0$ 附近系数放大、限制更严；同时 $r\to0$ 处 $\frac1r\frac{\partial}{\partial r}\left(r\frac{\partial C}{\partial r}\right)$ 出现 $0/0$，必须用极限形式 $\lim_{r\to0}=2\left.\frac{\partial^2C}{\partial r^2}\right|_{r=0}$ 或对控制体直接积分（控制体积法）规避。**评分提示：给出"网格数/时间步减半后结果变化 <1%"的收敛性验证表，比空口声称"精度足够"有效得多。**

5. **扩散系数对含水率的强非线性。** $D_{\text{eff}}$ 随含水率下降可跨若干数量级 [S8]；用单一常数 $D$ 只能得到"表观"结果。若题目要求变扩散系数，应给出 $D(C)$ 的显式形式并做灵敏度分析。

6. **忽略收缩会系统性高估扩散系数。** 固定网格 + 固定半径而物料实际收缩，等效于把同样的水分通量摊到更大的截面上。实测证据：忽略高度收缩时 $D_{\text{eff}}$ 被高估 [S2]；正确做法是引入移动边界/ALE 或 $R(t)$ [10][11][12]。

7. **潜热导致表面与内部降温，不可省略汽化汇项。** 蒸发吸热使物料温度低于热风温度，实验中可观测到中心温度演化 [9]；忽略潜热项会高估温度场、进而高估 $D_{\text{eff}}$ 并低估干燥时间 [13][14]。

8. **变物性不是可选项。** [15] 通过对比计算表明取常数物性会带来系统性偏差；[16] 给出密度、导热、比热随含水率的实测变化。建议在论文中至少做"常数物性 vs 变物性"两组结果对比，量化差异——这是最容易拿到的方法论加分点。

9. **量纲与符号一致性自查。** 逐式核对：$D$ [m²/s] × $\partial C/\partial r$ [kg/(m⁴)] = 通量 [kg/(m²·s)]；$h_m$ [m/s] × 浓度差 [kg/m³] = 通量 [kg/(m²·s)]；$k\partial T/\partial r$ [W/m²]；$\rho c_p \partial T/\partial t$ [W/m³] 与 $L_v$ [J/kg] × 体积汽化速率 [kg/(m³·s)] = [W/m³] 匹配。单位不匹配的方程在评阅中几乎必然被扣分。

10. **经验模型的选择要有指标而非直觉。** 拟合 Page / Midilli / Newton / 对数等模型时，应同时报告 $R^2$、$\chi^2$、SSE、RMSE（[8] 的就是这套指标），并用残差图佐证；[7] 的 Midilli 模型在 Page 之上多了 $bt$ 项，晚期拟合通常更优。
