# 03 ABC 各题型解法特点

> 建模手主责方法设计，代码手主责算法/工具/求解器。

---

## 一、A 题（机理）："机理方程 + 数值求解 + 参数反演"

1. **机理建模是主旋律**：偏微分方程/非线性方程组建立后，几乎无解析解，统一落到 **有限差分（后向欧拉、Crank-Nicolson、追赶法解三对角）、搜索算法（二分/黄金分割/遍历/变步长）、fsolve**。
2. **参数反演是隐藏考点**：2018A 用实验温度反演换热系数；2017A 反求旋转中心、增益系数。手段统一是**最小二乘拟合实测数据**。
3. **优化几乎全是"多目标转单目标"**：熵权法、权重比、或直接"最小厚度=最优"把优化目标物理化。决策变量少（1~3 个），遍历/二分就够，不需要复杂智能算法。
4. **做"修正模型/扩展模型"体现深度**：2016A 修正"锚链着地"、2017A"镶边"处理旋转中心不重合。

## 二、B 题（优化）："自定指标 + 0-1/整数建模 + 启发式求解 + 递进展开"

1. **0-1/整数变量离散建模**：2016B 用 `x_i∈{0,1}` 表示"路口开放/不开放"，总通行能力写成 `C总 = Σ x_i·C_i`。**套路：把离散决策写成 0-1 变量再线性叠加，避免直接枚举。**
2. **先证明可行性/上下界**：2018B 先证明"RGV 循环最短用时"和"系统最优上限"，给结果做上界背书。**加分项是"先给理论界，再证明求解结果逼近它"。**
3. **"评价指标 + 优化模型"二段式**：先定指标（里程利用率、供求比、延误时间差），再围绕指标建优化。
4. **求解偏启发式/搜索 + 仿真验证**：模拟退火、深度搜索、最大流启发式、元胞自动机仿真、多阶段决策。
5. **递进式场景展开**：2018B 一道工序→两道工序→故障风险；每递进一层在原模型上加约束。

## 三、C 题（数据）："清洗 → EDA → 特征工程 → 由简到繁 → 误差评价"

```
数据清洗 → 可视化探索 → 特征工程 → 模型（由简到繁） → 误差评价
```

1. **数据预处理**：SQL/Excel/Python 去重、关联、无效记录筛选、异常值删除。
2. **特征工程（决定论文高度的关键）**：
   - 降维：RGB 三通道高度自相关 → 合成灰度。
   - 指标构造：RFM 细化为 RFMT、百分位打分、滑动时间窗口。
3. **模型选择（由简到繁是固定套路）**：一元线性 → 二次多项式 → 非线性/Logit/Michaelis-Menten 修正 → 聚类/转移矩阵/关联规则。
4. **误差评价**：R²、F 检验、p 值、MRE、变异系数、残差图（每篇至少 2 种）。

> **关键**：C 题的标配叙事是"**简单模型 → 发现不足 → 更复杂模型改进**"的递进结构。直接上黑箱模型反而失分。

## 四、LINGO 优化软件（B 题/C 题优化子问题专用）

**定位**：语法接近数学公式表达，适合快速验证优化模型结构（线性规划、整数规划、非线性规划）。B 题和部分 C 题的优化子问题可用 LINGO 快速建模，与 Python 互补——LINGO 验证模型结构，Python 做数据预处理和可视化。

**基本语法**：
- `SETS` 定义集合
- `DATA` 赋值
- `MIN/MAX` 目标函数
- `@FOR/@SUM` 约束

**应用案例**：2021B 获奖论文有直接用 Lingo 做连续寻优的案例。
