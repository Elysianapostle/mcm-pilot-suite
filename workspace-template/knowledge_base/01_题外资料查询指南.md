# 01 题外资料查询指南

> 建模手主责，代码手/论文手协助。**题外资料是拉开档次的隐性分。** 题目只给"场景 + 数据 + 少数参数"，建模必需的定律/公式/常数/标准几乎全在题外。优秀论文普遍引 4~9 篇文献/规范为外料背书。

---

## 一、A 题（连续/机理）：查"物理定律 + 经验公式 + 常数"

| 真题 | 必须查的题外知识 | 论文实际引用的出处 |
|---|---|---|
| 2016A 系泊 | 近海风荷载、水流力公式、悬链线方程、浅水流速抛物线分布、锚链国标 | 郝春玲（国家海洋二所）、`GBT549-1996` |
| 2015A 太阳影子 | 太阳高度角公式、时角、赤纬角、地方时换算 | 武琳（天津大学硕论） |
| 2017A CT | 朗伯-比尔定律、Radon 变换、中心切片定理、FBP/ART、去噪 | 郝国防/张朋《CT 图像重建算法比较》 |
| 2018A 服装 | Fourier 定律、热传导方程、空气层 <6.4mm 只导热、44℃ 热损伤阈值 | 潘斌（浙理工硕论）、杨世铭《传热学》 |

**去哪找的命中率排序**：① **对口硕士/博士论文**（参数最全、公式现成，是 A 题第一来源）→ ② 学报/期刊 → ③ 国标/行业规范 → ④ 教材 → ⑤ 百科（补概念）。

**关键细节**：物理常数也要注明出处，如 2016A 某论文写"重力加速度 9.80655（南海黄岩岛附近）、钢球/锚链密度 7.85g/cm³"。**参数有没有出处，是区分一二等奖的细节。**

---

## 二、B 题（离散/优化）：查"国家标准 + 经验值 + 商业数据"

约束取值有 4 类稳定来源（从硬到软）：

1. **国标/行业规范**（最硬、最有说服力）：2016B 直接引 `GB 城市双车道公路设计速度`、`GB 城市道路一条车道通行能力`、`GB 信号交叉口服务水平`、车道折减系数。
2. **行业经验值/阈值**：里程利用率理想值 70%、万人拥有量 20 辆（2015B）、打包半径 1.5km（2017B）。
3. **公开商业数据（自搜集）**：2015B 明确要求"搜集相关数据"，获奖论文用深圳/西安/拉萨三城统计 + 滴滴披露车辆数。
4. **理论模型经典参数**：元胞自动机 NS 规则、Greenshields 线性 k-v 关系、贝叶斯-纳什均衡。

**规律**：能查到的国标优先写进表（"表 X GB…"）+ 参考文献上标；查不到的用"经验值 + 一句依据说明"兜底，**绝不拍脑袋给裸数字**。

---

## 三、C 题（数据）：查"标准公式 + 现成模型 + 行业阈值"

数据题**不缺方法，缺"用什么标准/公式把原始数据变成可建模特征"**，共四类：

1. **专业领域标准公式**（核心）：2017C 用 RGB/HSV 颜色空间转换 + 灰度公式；2018C 用 RFM/RFMT/FMS 客户价值模型。
2. **跨领域现成模型**（高分套路）：2017C 借生化 Michaelis-Menten 模型做比色饱和；2018C 借营销学 AHP、K-means、马尔科夫链、关联规则。
3. **行业标准/经验阈值**：变异系数 CV>15% 判异常、样本容量 n≥30、Saaty 1-9 标度与 RI 表。
4. **领域常识/经典案例**：2018C 引"尿布与啤酒"关联规则案例。
