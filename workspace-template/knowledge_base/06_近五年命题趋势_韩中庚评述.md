## 6.1 工具链：Python 生态全面取代 Matlab（最硬的变化）

- 老论文清一色 Matlab；近五年获奖论文几乎全用 Python：`numpy/pandas/matplotlib` 打底，`scipy.optimize`（minimize/SLSQP）、`cvxopt`（凸二次规划）、`sklearn`、`tqdm` 常见，2023 C 题出现 **BONMIN 混合整数非线性求解器**、**GRU 深度学习**。
- **LINGO 优化软件**：语法接近数学公式表达，适合快速验证优化模型结构（线性规划、整数规划、非线性规划）。B 题和部分 C 题的优化子问题可用 LINGO 快速建模，与 Python 互补——LINGO 验证模型结构，Python 做数据预处理和可视化。2021B 获奖论文有直接用 Lingo 做连续寻优的案例。
- 支撑材料从"程序代码附录"进化为 **GitHub 开源仓库**（模块化、requirements.txt、3D 可视化/多帧动画）。
- 一个漂亮工程技巧：**把高维非线性规划降维成凸二次规划**（2021 A 用 cvxopt），精度与速度双赢。

## 6.2 A 题：从"偏微分方程离散"转向"解析/递推 + 数值求根 + 蒙特卡洛模拟"

- **2022 波浪能（过渡分水岭）**：微分方程从 PDE 降为 **ODE**，水动力系数（附加质量/兴波阻尼）被"外包"成附件参数，难点从"自己离散解 PDE"转移到"受力建模 + 参数寻优"。寻优两阶段化——"全局遍历→局部细化"与"粗搜 + 遗传算法精搜"，**GA 首次进入 A 题**；还有"稳态频域复数法解析解 vs 数值解"对照、假设逐条闭环检验。**定位：脱掉老 A 题 PDE 外衣、寻优尚未全面智能化的过渡样板。**
- 2024 板凳龙：极坐标螺线 + 微分方程分离变量积分得解析式 + 余弦定理递推 + 二分/三分求根，完全不碰有限差分。
- 2023 定日镜场：蒙特卡洛光线追迹（统计模拟）替代确定性求解。
- 老 A 题标配"参数反演"基本退场，取而代之的是 **双层/多层规划**（上层定全局参数、下层定局部参数反复迭代）。
- **智能优化从"试水"变"主力"**：2024 用 PSO 并对比弃用模拟退火；2023/2021 仍用枚举也拿了国一。到 2025 烟幕弹，**差分进化 DE 已升为主力求解器**（8 维、罚函数处理约束），PSO 退居交叉验证工具。机器学习/深度学习仍未进入 A 题主流。
- **2025 A（烟幕干扰弹）新看点**：① **AI 使用说明成硬性要素**——参考文献[1] 直接引 DeepSeek-V3.1、附录附"AI 使用说明.docx"，是 2025 官方新规的首个体现；② **布尔函数 0-1 建模**——`总遮蔽时长 = ∫Bool(t)dt` 统一表达"导弹视线是否被烟幕遮蔽"，简洁且便于算法实现；③ **几何降维**——问题四用"预测拦截点"把 12 维降为低维初值再局部网格搜索，配凸性证明（只需判圆柱上下底圆周是否被完全遮蔽），体现"几何洞察先降维再优化"的进阶；④ **无蒙特卡洛**（确定性几何，MC 缺席——A 题并非每年都要 MC）；⑤ **MATLAB 未被 Python 取代**（这篇仍全套 MATLAB，工具选择仍看队伍）。

## 6.3 B 题：从"纯 0-1 规划"走向"几何/物理机理 + 概率决策"（近五年最大转向）

> 近五年 B 题发生了国赛史上最彻底的题型迁移：从 2011B/2018B 的离散优化（0-1 规划、调度），一路走到 2025B 的物理光学机理。这是当前 B 题最重要的认知更新。

- **2021 B 乙醇偶合制备 C4 烯烃**（评价 + 回归 + 连续优化）：B 题里唯一的"统计建模"题，0-1 规划第一次缺席——给的是 **21 组催化剂的实验数据表**（不是"要你规划的实体"），建模对象是**变量间的统计关系**。4 篇论文方法高度共识：**关联**用"皮尔逊相关 + 曲线拟合"（二次/三次/指数/Logistic，R² 普遍 >0.9）；**显著性**用"方差分析 / 逐步回归 / PCA / PLS / 多重比较"（B026 双因素方差分析最系统）；**收率建模**把催化剂拆成 5~6 个自变量做多元回归（逐步回归消共线性）；**寻优**用连续优化（quadprog / fmincon / Lingo，仅 B050 用 BP 神经网络）。关键认知：**答案不唯一**（四篇最优收率 28%~46%，评分看拟合合理性与显著性论证，而非唯一最优值）；**0-1 与启发式经验在这里基本失效、反而误导**——正确打开方式是"化学机理定性 → 统计关联/显著性 → 回归收率模型 → 连续寻优"四段式，问题四的"增补实验设计"（均匀/正交设计）才是特有考点。
- **2022 B 无人机纯方位无源定位**（几何定位 + 优化）：B 题"几何化"的起点——建模对象从"离散决策变量"变成**连续几何坐标**。三篇论文的共识模板：**问一**统一走"极坐标 + 正弦定理"（两圆求交/等角对等边定位）；**问二**结论惊人一致——"除基准机外仅需 +1 架"（但证明方法三分：遍历+仿真 / 角度区间交集判空 / 引理+集合唯一性）；**问三/四**是"定位→沿偏移向量调整→迭代/启发式搜索"。**正弦定理是三篇共同地基**（而非 0-1 规划），"每架知道自身编号"是必设假设。档次靠**误差分析 + 数学证明**拉开（B086 三条引理 + 正态扰动灵敏度分析，B035 严格误差范围分类讨论），而非求解器。**增量**：0-1 规划 / Lingo-Cplex 运筹套路整体失灵，解析几何建模 + 计算几何（两圆求交/旋转矩阵/叉积）+ 凸/局部优化（L2 loss 估价函数、邻域搜索）上位，"解析解推导 + 数学证明"成为新硬门槛。
- **2023 B 多波束测线**（几何机理 + 优化）：B 题"几何化"彻底完成——
  - 四问全靠 **正弦定理 / 相似三角形 / 线面角 / 向量叉乘 / 圆锥截面**，几乎没有微分方程。
  - **第一问公式三家一致**，真正的分水岭是 **"坡面重叠率怎么定义"**：三篇给了三种处理，敢对官方定义做批判性修正并论证是高分段拿分点。
  - 测线方向必"平行等深线"，答案收敛到 34 条。
  - **问题 4 拉开档次**：低配"分区 + 最小二乘拟合坡面 + 复用问题 3"，高配"随机森林拟合地形(R²≈99.9%) + 改进飞蛾火焰算法寻路"。
- **2024 B 生产决策**（概率期望 + 0-1 决策 + 序贯决策）：B 题首次把"**随机序贯决策**"整包带入。问题三三种主流解法都可行：**动态规划** / **模拟退火** / **遗传算法**。核心假设三篇一致：**"拆解后质量不确定必须检测，防次品无限循环"**。**增量**：概率统计（假设检验/功效函数/贝叶斯）成为新硬门槛。
- **2025 B 碳化硅外延层**（物理光学机理 + 数值反演）：B 题第一次纯物理光学题。标准模板：① **折射率建模是第一性关键**；② **厚度反演统一"两步法"**——FFT 频域粗估初值 → 非线性最小二乘精拟合；③ **可靠性检验极重**（置信区间、Q-Q、敏感性、残差诊断）。**AI 工具首次进入参考文献**。

## 6.4 C 题：机器学习/深度学习全面铺开（但 2024 起转向数据 + 优化）

> 以下各年份末的"评述"来自韩中庚教授 2020-2025 C 题讲座。

- **2020 C（中小微企业信贷策略）**：PCA 降维 → 多模型融合评分 → 信贷组合优化。
  - **评述**：① 特征选择是核心前提；② 可解释性需平衡；③ 风险是动态的，需引入马尔可夫链。
- **2021 C：仍偏传统优化**（综合评价 + 0-1 整数规划 + 动态噪声模拟）。
  - **评述**：① 模型复杂度与求解效率矛盾；② 不确定性需量化（两阶段随机规划/鲁棒优化）；③ 警惕"局部最优陷阱"。
- **2022 C（玻璃成分）**：有监督+无监督+降维+集成系统性铺开。
  - **评述**：① **定和约束是核心难点**——必须用 CLR 变换消除；② 特征提取决定分类成败；③ 考古可解释性。
- **2023 C（蔬菜补货）**：ARIMA + GRU + BONMIN。
  - **评述**：① 多因素综合考量是突破瓶颈（天气、节假日）；② 计算效率是工程化关键；③ 需求不确定性需量化。
- **2024 C（农作物种植策略）**：题型反转——数据+LP/MIP 优化，无一用 ML。
  - **评述**：① 主观因素量化是难点；② 模型需适配时空尺度；③ 数据可得性是前提。
- **2025 C（NIPT 时点选择）**：医学统计推断。**纯统计派 vs 统计+深度学习派**，两路线都可获奖。
- **定和约束是 C 题拉开档次的关键方法点**：CLR 变换消除定和约束效应，ilr 处理零值。

## 6.5 写作：摘要结构化 + 数字精确化 + "证明/验证"仪式化

- 摘要从"总-分-总"变成"分问题 + 6 位小数精确结果 + 点明算法名与对比结论"。
- 兴起「模型准备/证明」小节、「验证」小节、**算法对比选优论证**。
- 算法流程图大幅增加（2024 每问一张）。
- 题外资料从"现成公式/国标"转向"**算法文献 + 自建模型**"。

## 6.6 题型分布规律

- **A 题**持续"物理机理 + 优化"，机理从"偏微分方程"扩展到"解析几何/运动学/光学"。
- **B 题**（五年最大转向，纯 0-1 规划彻底退场）。
- **C 题**（波动最剧烈，非单向加码）。

## 6.7 C 题四维趋势框架（韩中庚教授讲座核心观点）

**趋势一：从经典到前沿**——ML/DL 深度融合，但经典方法仍是基础。

**趋势二：从静态到动态**——时序预测、动态定价、滚动优化。

**趋势三：从确定性到不确定性**——蒙特卡洛场景、CVaR、FDR 多重检验。

**趋势四：从模拟数据到真实场景**——数据噪声、样本不平衡、标签噪声。

**跨学科融合核心动力**
- 领域知识是建模的逻辑基石
- 交叉视角突破单一思维局限

**核心能力要求**
| 能力维度 | 备赛策略 |
|---|---|
| 数学基础 | 回归分析、假设检验、规划论、随机过程 |
| 编程技能 | AI 辅助编程，但需理解算法原理 |
| 数据分析力 | pandas/sklearn 基本功，matplotlib/plotly |
| 创新思维 | 多看跨学科方法论 |
| 团队协作 | 明确分工、即时沟通 |
| 学术写作 | 研读优秀范文 |
