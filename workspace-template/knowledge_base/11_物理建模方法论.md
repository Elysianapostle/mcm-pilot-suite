# 物理建模方法论——从第一性原理出发

> **使用场景**：物理手 Agent 的核心理念框架。当题目涉及物理/几何/力学/光学/电磁/流体等机理时，必须从第一性原理出发，而非套用现成公式。

---

## 一、核心原则

### 1.1 先分类，再建模

拿到物理题后，先判定属于以下哪一类：

| 类别 | 特征 | 典型建模方法 | 常见陷阱 |
|------|------|-------------|---------|
| **刚体运动学/几何约束** | 刚体链、连杆机构、铰链、轨迹 | DAE（微分代数方程），约束动力学 | 把几何约束当成优化目标 |
| **连续介质力学** | 弹性体、流体、振动、传热 | PDE（偏微分方程），有限元/差分 | 边界条件缺失 |
| **波动/光学** | 干涉、衍射、偏振、反射 | Fresnel 公式、Airy 公式、波动方程 | 忽略多光束、忽略色散 |
| **电磁学** | 电场、磁场、天线、电磁波 | Maxwell 方程、传输线理论 | 边界条件、近远场区分 |
| **统计物理/热力学** | 热平衡、熵、相变、粒子系统 | 统计分布、Boltzmann 因子 | 平衡态假设不成立 |

### 1.2 第一性原理三步法

**第一步：识别自由度和约束（最重要）**

- 系统有多少个自由度（DOF）？
- 有多少个约束（几何约束、运动学约束、守恒律）？
- 如果 DOF = 约束数 → 系统是**完全约束**的DAE，**不应该有**目标函数
- 如果 DOF > 约束数 → 系统有冗余自由度，需要额外的物理原理（最小势能、最小作用量）来唯一确定解

**关键判断**：看到"优化"或"目标函数"时，先问自己——这个系统的物理本质真的是优化问题吗？还是一个约束动力学问题被人为地加上了目标函数？

**第二步：列出所有物理定律**

- 几何关系：勾股定理、弧长公式、曲率公式
- 运动学：速度合成、加速度分解、刚体运动
- 动力学：牛顿第二定律、动量守恒、能量守恒、角动量守恒
- 热力学：热力学第一/第二定律
- 电磁学：Maxwell 方程组、Kirchhoff 定律
- 波动学：Huygens 原理、Fermat 原理、Snell 定律

**第三步：数学形式化**

- 用符号表示所有变量
- 写出所有约束方程（等式和不等式）
- 确定初始条件和边界条件
- 选择求解方法（解析解/数值解/渐近解）

## 二、常见物理陷阱

### 陷阱 1：时间域 vs 空间域（最致命）

**症状**：把系统的"惯性"或"记忆"效应建模成时间域上的显式方向依赖。

**案例**：Q2 板凳龙铰链链模型。错误做法：最小化相邻时刻的方向变化（≈ 添加扭转弹簧）→ 人为引入势能。正确做法：链的方向由**空间曲率约束**决定，不是由时间方向记忆决定。DAE 约束动力学中，每一时刻的位置由当前边界条件唯一确定，与前一时刻无关。

**辨别的关键问题**：系统的"记忆"来自物理机制（如塑性变形、滞后效应），还是来自数值求解的初值依赖？如果是后者，不要把它建模成目标函数。

### 陷阱 2：目标函数幻觉

**症状**：给一个本不需要优化的系统添加目标函数，把约束问题变成优化问题。

**案例**：Q2 的链系统是 223 个自由度 + 223 个约束 = 完全约束的 DAE。任何形式的"最小化方向变化"都等价于添加了额外的弹簧势能，物理上改变了系统本身。

**正确做法**：
- 完全约束系统 → 直接求解约束方程（线性/非线性方程组）
- 欠约束系统 → 需要额外的物理原理（最小势能、最小作用量、最小耗散）
- 过约束系统 → 需要最小二乘意义的"最优"解

### 陷阱 3：边界条件缺失

**症状**：只关注内部方程，忽略了边界条件对解的决定性影响。

**常见情况**：
- 微分方程少给了边界条件 → 解不唯一
- 几何约束少给了端点条件 → 链的位置/方向不唯一
- 给出了隐含假设（如"光滑"、"无摩擦"）但未显式说明

### 陷阱 4：量纲和单位不一致

**症状**：公式中量纲不匹配，或者单位换算错误。

**检查方法**：每个方程左右两边的量纲必须一致。长度、时间、质量、角度是基本量纲。

### 陷阱 5：混淆"连续"和"离散"

**症状**：把连续系统离散化后，误以为离散效应是物理效应。

**案例**：链的杆长是离散的，但螺线是连续的。链的"折线"形状不是物理效应，而是离散化带来的数值近似。区分：哪些是物理必须的，哪些是数值近似。

## 三、物理手自检清单

物理手输出前，必须逐条自查：

1. **自由度分析**：是否明确计算了系统的自由度和约束数？
2. **有无不必要的目标函数**：完全约束系统是否引入了虚假的目标函数？
3. **边界条件**：所有边界条件是否都已明确（包括初始条件）？
4. **量纲检查**：所有公式的量纲是否一致？
5. **物理定律**：是否从基本物理定律出发，而不是从现成公式出发？
6. **模型类型**：是否明确是 DAE / PDE / ODE / 优化 / 统计中的哪一种？
7. **假设合理性**：每条假设是否有物理依据？是否与实际情况冲突？
8. **陷阱标注**：是否标注了该问题常见的物理陷阱？

## 四、典型物理模型速查

### 4.1 铰链链/连杆机构

- **模型类型**：DAE（微分代数方程）
- **自由度**：每个铰链 2 个平移自由度 - 约束方程数
- **约束类型**：杆长约束（刚性连杆）、铰链约束（只能旋转）
- **求解方法**：牛顿-拉弗森迭代法解非线性方程组，或用广义坐标 + Lagrange 乘子
- **常见错误**：给 DAE 系统加目标函数（如"最小化方向变化"）

### 4.2 薄膜干涉（Fabry-Perot）

- **模型类型**：前向模型 + 反演优化
- **前向模型**：Fresnel 反射系数 → Airy 多光束干涉公式
- **反演**：最小二乘拟合（目标函数是物理的，因为数据有噪声）
- **关键参数**：厚度 d、折射率 n(λ)（含色散）、入射角 θ
- **常见错误**：单初值优化、忽略色散、忽略 Reststrahlen 区

### 4.3 弹性力学/结构力学

- **模型类型**：PDE（偏微分方程）
- **控制方程**：Navier-Cauchy 方程（各向同性弹性体）
- **边界条件**：Dirichlet（位移）/ Neumann（应力）
- **求解方法**：有限元法（FEM）或有限差分法
- **常见错误**：边界条件缺失、材料参数不匹配

### 4.4 流体力学

- **模型类型**：PDE（Navier-Stokes 方程）
- **关键参数**：Reynolds 数（层流/湍流判断）
- **简化方法**：势流理论（无旋）、边界层理论（高 Re）
- **常见错误**：忽略可压缩性、湍流模型选择不当

## 五、物理手输出格式

物理手必须输出结构化 JSON（不要 markdown 代码块包裹）：

```json
{
  "analysis": "物理情景分析（Markdown，含受力分析、自由度计算、约束分析）",
  "model_type": "DAE|PDE|ODE|优化|统计|其他",
  "dof_analysis": "自由度分析：DOF = X，约束数 = Y，结论 = 完全约束/欠约束/过约束",
  "governing_equations": ["控制方程1", "控制方程2", "..."],
  "boundary_conditions": ["边界条件1", "边界条件2", "..."],
  "constraints": ["约束1", "约束2", "..."],
  "common_traps": ["常见陷阱1（如：不要把DAE系统当成优化问题）", "..."],
  "assumptions": ["假设1：物理依据", "假设2：物理依据", "..."],
  "to_modeler": "给建模手的物理分析结论（结构化文本，含必须遵守的物理约束）",
  "self_check_passed": true
}
```
