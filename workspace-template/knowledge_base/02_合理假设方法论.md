# 02 合理假设方法论

> 建模手主责定假设，论文手协助写进正文。

---

## 一、假设的"三档"（通用，最重要）

| 档次 | 特征 | 实例 |
|---|---|---|
| **✅ 标配（安全不扣分）** | 几乎每篇都写 | "题目数据真实可靠"、"忽略突发事件/极端天气"、"实际路程≈直线距离"、"决策者理性" |
| **🌟 加分（化简 + 依据）** | 把复杂现实化简到可建模，且**给出依据** | 降维假设、独立性假设、参数归一化，且每条带物理/文献理由 |
| **❌ 扣分（要避开）** | 假设把结论/本质假设掉了 | "假设补贴有效"（同义反复）、"各深度流速相等"（抹掉题目核心） |

## 二、各题型的假设套路

### A 题（机理）：假设 = 把复杂物理对象"降维 + 理想化 + 忽略次要效应"

- **降维**（A 题最核心的化简）：2018A 服装把三维传热降为**一维**（理由"只考虑垂直皮肤方向"）；2016A 系泊把三维空间降为**平面受力**（理由"各方向平衡时状态相同"）。
- **对象理想化**：刚体不变形、介质均匀、各向同性、材料参数不随环境变。
- **忽略次要效应**：忽略热辐射/对流、忽略衍射/折射/散射、忽略海底摩擦。
- **边界理想化**：海床/海面水平、地表绝对水平。

### B 题（优化）：假设 = 固定场景 + 独立性 + 参数归一化

- **几何/物理化简**：2016B"周边道路均为双车道、坡度 0、只考虑四轮标准车"。
- **独立性**：2016B"开放的交叉路口相互独立"——把 NP 难耦合拆成可叠加。
- **对称性/结构**：2016B"小区周围均为双向四车道主干道"——固定标准场景再逐类展开。
- **参数归一化**：2017B 把信誉值 log 变换压到 0.2~0.8，消量纲又保序。

### C 题（数据）：假设 = 把"没明说的定义"补全

- **数据质量类**：数据真实合理、录入无时间差、一条记录=一次消费。
- **环境一致性类**：拍摄环境一致、同一设备、试纸未过期。
- **业务规则类**（数据题特有、最重要）：什么是"活跃"？什么是"促销"？什么算"一次消费"？——**不定义清楚就无法构造特征**。

## 三、加分的两个进阶套路

1. **假设要能被检验**：2018A 某论文专门做"考虑热辐射的扩展模型"，对比换热系数 113 vs 8.496，用数据证明"忽略热辐射合理"。
2. **假设写"可行性论证"**：2016B 某论文写"3.1 假设内容 + 3.2 假设可行性"逐条自证，是标杆。**只列假设不做一致性检查是扣分点。**
