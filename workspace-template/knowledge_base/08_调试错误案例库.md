## 一、PBC 仿真调试实录（2026 华数杯 A 题 问题 1/2）

### 1.1 问题简述

微构体 10×10×10 μm³ 立方体，内含随机取向的圆柱形导电介质 A（半径 30nm，高 5000nm）。周期性边界条件（PBC）：介质 A 超出立方体边界的部分从对面重新进入，视为独立介质。判断介质间是否连通、左右表面是否导通。

### 1.2 错误 1：边界条件理解错误导致 100% 导通

**错误代码**：用 PBC 下的线段-表面距离，将 x=-5000 和 x=+5000 视为同一表面。

```python
# 错误：PBC 下 d_left = d_right，一个介质同时连 SRC 和 DST
def seg_to_surface_pbc(p1, p2):
    # 取 27 镜像中最小的距离，左右表面不加区分
```

**后果**：只要有一个介质连上表面，它同时连 SRC 和 DST，形成 1-hop 路径，三组全部导通，概率 100%。

**正确做法**：左右表面是两个独立的物理实体（带电表面），不能通过 PBC 等同。线段到 x=-5000 和 x=+5000 的距离要分别计算，无 PBC。

```python
def seg_to_surface(p1, p2, target_x):
    """线段到指定平面的最短距离（无 PBC）"""
    dx = p2[0] - p1[0]
    candidates = [0.0, 1.0]
    if abs(dx) > 1e-12:
        t = (target_x - p1[0]) / dx
        if 0 <= t <= 1:
            candidates.append(t)
    return min(abs(p1[0] + t * dx - target_x) for t in candidates)
```

**教训 ①：边界条件优先原则**。写代码前先把"表面怎么判定"用自然语言写清楚——左右表面是独立的还是等同的？PBC 适用于段-段距离，但不适用于段-表面距离。**边界条件是建模的一部分，不是代码细节**。

### 1.3 错误 2：线段距离算法符号错误 → 段间连接全漏

**错误代码**：两线段最短距离的核心公式中，`tq` 的符号反了。

```python
# 错误：s = (b * t - e) / c  应为  s = (b * t + e) / c
# 从方程 -b*sp + c*tq = e → tq = (e + b*sp)/c，不是 (e - b*sp)/c
```

**后果**：段间距离计算值偏大，段间连接几乎全部漏判。但恰好被错误 1（表面 100% 导通）掩盖，看不出问题。直到改正错误 1 后三组全不导通，才发现段间距离有 bug。

**教训 ②：Bug 相互掩盖是调试中最危险的情况**。一个 bug 让你的结果 100% 对，另一个 bug 让结果 0% 对，叠加产生"看起来合理"的中间值，你会误以为代码正确。**永远不要相信只有一种方式验证的结果**——至少用两种独立方法交叉验证。

### 1.4 错误 3：空间哈希在 PBC 下漏判跨边界连接

**错误代码**：常规空间哈希（cell_size=200nm）只检查中点在同一单元格或相邻 27 单元格内的段对。

```python
# 错误：空间哈希按中点坐标分桶，但 PBC 下相距 10000nm 的段可能是邻居
for di in (-1, 0, 1):
    for dj in (-1, 0, 1):
        for dk in (-1, 0, 1):
            nkey = (cx + di, cy + dj, cz + dk)  # 只覆盖 ±200nm 范围
```

**后果**：5000nm 长的介质 A 横跨 25 个空间哈希格，其链路可能穿过周期性边界——介质 A 的一端在 x≈+5000、另一端在 x≈-5000，它们的中点分属哈希格的两端，距离 10000nm，被空间哈希漏掉。导致段间连接数只有 48-99，远低于理论值（~77-310），导通概率偏低。

**修复方案**：两重保障——(1) 空间哈希仍用常规方式覆盖大部分对；(2) 额外检查靠近对面边界的段对，用 PBC 距离判断。

```python
# 补充：靠近 x=-5000 的段 vs 靠近 x=+5000 的段
for i in left_near:
    for j in right_near:
        d = seg_seg_dist_pbc(segs[i], segs[j])  # PBC 距离
        if d <= SEG_SEG_THRES:
            adj[i].append(j); adj[j].append(i)
```

**教训 ③：加速结构必须匹配度量空间**。PBC 改变了空间的拓扑——立方体的对面是相邻的，但空间哈希假设"相邻 = 中点近"。当你的加速结构假设和物理空间假设不一致时，结果是**系统性的漏判**（不是随机误差，而是结构性的缺失）。**先确认加速结构的假设与问题物理假设一致，再优化性能**。

### 1.5 调试方法论总结

| 阶段 | 错误做法 | 正确做法 |
|---|---|---|
| 写代码前 | 直接写，边写边想边界条件 | 先写自然语言描述"表面怎么判定""PBC 适用于哪些距离" |
| 调试时 | 只看最终结果（导通/不导通） | 打印中间量：段间连接数、表面连接数、各段距离 |
| 发现 bug | 改一个地方就重跑 | 每次只改一个变量，确认它对结果的影响方向后再改下一个 |
| 验证 | 一种方法跑出结果就信了 | 至少两种独立方法交叉验证（如枚举 vs 空间哈希） |
| 加速结构 | 直接套用常规方案 | 先确认加速结构的假设与物理空间假设一致 |

## 三、Fabry-Perot 薄膜干涉厚度反演调试（2025B 题）

### 3.1 问题简述
2025 国赛 B 题：用红外干涉反射光谱测量 SiC/Si 外延层厚度。物理模型为 Fabry-Perot 多光束干涉（Airy 公式），需要从反射率数据反演厚度 d 和色散参数。

### 3.2 错误 1：优化器收敛到边界废值（d=0.0μm）

**现象**：代码手输出的厚度结果为 0.000μm 或 0.005μm，明显超出物理范围 [1.0, 50.0]μm。

**根因**：
1. **scipy.optimize.least_squares 未设置 bounds** - 默认无边界约束，参数可以跑到任意值
2. **单初值优化** - FP 目标函数有巨量局部极小值，单初值几乎必收敛到错误局部最优
3. **缺乏网格搜索** - 没有先做粗粒度网格搜索获得较好初值，直接丢给 BFGS/LM

**正确做法**：
```python
# 1. 先网格粗搜
d_grid = np.linspace(1e-6, 50e-6, 50)  # 50 个点
costs = []
for d0 in d_grid:
    res = np.sum((R_obs - forward_model(d0, ...))**2)
    costs.append(res)
best_idx = np.argsort(costs)[:3]  # 取前 3 个

# 2. 每个初值独立 LM 优化，带 bounds
results = []
for idx in best_idx:
    res = least_squares(residuals, [d_grid[idx]], 
                        bounds=([1e-6], [50e-6]),  # 必须设置
                        args=(nu, R_obs, ...))
    results.append(res)

# 3. 选代价最小的
final = min(results, key=lambda r: r.cost)
```

### 3.3 错误 2：同一材料作为薄膜和衬底

**现象**：正向模型测试中反射率几乎没有变化（0.1907-0.1915）。

**根因**：SiC/SiC 时 r2=0，界面无反射，没有干涉产生。

**正确做法**：SiC 外延层/Si 衬底结构，必须用不同材料参数。

### 3.4 错误 3：理论峰间距公式单位错误

**现象**：预期干涉峰数 0.2 个，显然不对。

**根因**：Δν = 1/(2nd) 中 d 的单位是 cm 不是 m。d=10μm=0.001cm 代入得 196 cm⁻¹。

**正确做法**：d 单位转换，或直接用 Δν = 1/(2nd_cm)。

### 3.5 核心教训
1. **前向模型验证是反演的前提** - 先写 test_fp_forward.py 验证模型正确，再做反演
2. **FP 反演必须多初值+网格搜索** - 单初值优化基本必失败，这是物理问题本身的特性
3. **scipy 优化必须设置 bounds** - 无边界约束时，参数可以跑到物理荒谬的值
4. **收敛到边界值 = 初值不当** - 如果 d=1.0μm 或 d=50.0μm，说明仍需回到网格搜索阶段
5. **日志标记行辅助系统检测** - [FORWARD_TEST]、[MULTI_START]、[FINAL_RESULT] 让系统能自动验证
