## 一、国赛 A/B/C 三题定位（一张表看懂）

| 题号 | 题型定位 | 典型场景 | 核心能力 | 评审看什么 |
|---|---|---|---|---|
| **A 题** | 连续型 / 机理类 | 微分方程、物理、工程（热传导、力学、光学、天文） | 物理建模 + 数值求解 | 假设有没有依据、机理图有没有画到位、结果有没有误差分析 |
| **B 题** | 离散型 / 优化类 | 图论、调度、组合优化、资源分配 | 离散建模 + 启发式/搜索 + 仿真 | 约束值有没有出处、可行性有没有证明、场景有没有递进 |
| **C 题** | 数据型 | 数据分析、统计、挖掘、画像 | 数据清洗 + 特征工程 + 模型选择 | 特征怎么构造、模型怎么由简到繁、误差怎么评价 |

**一句话记住**：A 题考"你能不能把物理问题用方程写出来"，B 题考"你能不能把离散决策用 0-1 变量建出来"，C 题考"你能不能把脏数据做成好特征"。

## 二、题目分类

### 2.1 五大题型（跨 ABC 题的横向分类）

| 题型 | 核心问法 | 判断标准 | 历年真题举例 |
|---|---|---|---|
| **优化** | 求最大/最小，资源怎么分配 | 输出是一个数/方案 | 2011B 交巡警、2018B RGV、2007B 公交 |
| **预测** | 预测未来数值/趋势 | 输出是一段序列/未来值 | 2003A SARS、2007A 人口、2014A 嫦娥 |
| **评价** | 多方案综合排序/打分 | 输出是一个排名 | 2012A 葡萄酒、2021B 乙醇 |
| **机理/动力学** | 描述系统随时间的演化 | 输出是一组方程 | 2020A 炉温、2018A 服装、2015A 太阳影子、2017A CT |
| **统计/数据挖掘** | 从数据找规律/关系 | 输出是模型/特征 | 2013B 碎纸片、2017C 颜色、2018C 会员、2016C 电池 |
| **图论/网络** | 路径、连通、流 | 输出是路径/流量 | 2007B 公交、2019C 机场、2011B 交巡警 |

> **注意**：国赛几乎每道题都是**混合题型**。A 题常是"机理 + 优化"（如 2016A 系泊 = 力学建模 + 厚度寻优）；B 题常是"评价 + 优化"（如 2015B 出租车 = 供求评价 + 补贴优化）；C 题常是"统计 + 评价"（如 2018C 会员 = RFM 画像 + 分层评价）。**主问题定主模型，子问题叠加子模型。**

### 2.2 选型决策树（拿到题先走一遍）

```
拿到题 → 先问：输出是什么？
  ├─ 一个数/方案（求最值）→ 优化类
  │     ├─ 线性 → 线性规划 LP
  │     ├─ 含 0-1/整数 → 整数规划 MIP
  │     ├─ 非线性/非凸 → 遗传/模拟退火/粒子群
  │     └─ 多目标冲突 → 先归一化再加权 / NSGA-II
  ├─ 一段序列/未来值 → 预测类
  │     ├─ 数据量 < 15 → GM(1,1) 灰色预测
  │     ├─ 纯时序 → ARIMA / 指数平滑/马尔科夫链/卡尔曼滤波
  │     ├─ 有影响因素 → 回归 / 随机森林 / XGBoost
  │     └─ 强非线性长序列 → LSTM
  ├─ 一个排名 → 评价类
  │     ├─ 有专家经验 → AHP
  │     ├─ 纯数据 → 熵权法
  │     ├─ 方案距离排序 → TOPSIS
  │     └─ 指标高度相关 → PCA + TOPSIS
  ├─ 一组方程（演化）→ 机理类
  │     ├─ 连续时间 → 常微分方程 ODE
  │     ├─ 空间扩散 → PDE / 有限差分
  │     └─ 离散/不确定 → 差分方程 / 蒙特卡洛
  └─ 从数据找规律 → 统计/数据挖掘
        ├─ 有标签 → 回归 / 分类
        └─ 无标签 → 聚类（K-means / 层次）
```

## 三、开工前 5 分钟检查清单（Quick Checklist）

1. **定题型**：输出是数/序列/排名/方程/规律？→ 走选型决策树。
2. **定题外资料**：A 题查硕博论文+国标、B 题查国标+经验值、C 题查标准公式+现成模型。
3. **定假设**：标配写全 + 每个"化简假设"附依据 + 避开"把结论假设掉"。
4. **定解法**：A 题机理方程+数值求解、B 题先判题型（统计回归/几何定位/物理机理/概率决策，勿默认 0-1 规划）、C 题特征工程+由简到繁。
5. **定插图**：建模阶段配机理/结构图，求解阶段配流程图，结果配对比图，结尾配灵敏度。**每道题每子问都要写可视化代码，边建模边出图**。
6. **定工具**：优化问题优先考虑 LINGO 快速验证模型结构，再与 Python 互补。
7. **定摘要**：最后写，逐题"方法 + 模型 + 具体数字"。
